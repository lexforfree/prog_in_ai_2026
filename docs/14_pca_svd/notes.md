## 1. Проблема: слишком много признаков

### Мотивация (5 мин)

Начать с конкретных примеров:

- **Изображение 64×64** → 4096 признаков  
- **Текстовый классификатор с TF-IDF** → 100 000 признаков  
- **Геномные данные** → 20 000+ генов на несколько сотен пациентов

Спросить студентов: *«Что происходит с KNN, когда признаков тысячи?»*

**Ответ:** Все расстояния становятся одинаковыми → алгоритм теряет смысл.

### Проклятие размерности (5 мин)

В $p$-мерном пространстве объём гиперкуба растёт как $L^p$. При фиксированном числе точек $n$ — плотность падает экспоненциально.

Формально: отношение минимального расстояния к максимальному стремится к 1:

$$\frac{d_{\min}}{d_{\max}} \xrightarrow[p \to \infty]{} 1$$

**Показать в ноутбуке:** гистограммы расстояний при $p = 2, 10, 100, 1000$.

### Что хотим?

Перейти из $\mathbb{R}^p$ в $\mathbb{R}^k$ ($k \ll p$), **сохранив максимум информации**.

Ключевой вопрос: **что такое «информация» в данном контексте?** → Дисперсия (разброс) данных.

## 2. Геометрия: проекции

### Постановка задачи

Пусть $X \in \mathbb{R}^{n \times p}$ — матрица данных ($n$ объектов, $p$ признаков).

Хотим найти **направление** $\mathbf{u} \in \mathbb{R}^p$, $\|\mathbf{u}\| = 1$, такое что **проекции данных на это направление максимально разнообразны**.

Проекция $i$-го объекта на $\mathbf{u}$:

$$z_i = \mathbf{x}_i^\top \mathbf{u} \in \mathbb{R}$$

### Интуиция (нарисовать на доске)

Представить облако точек в 2D. Если проецировать на ось $x$ — получим одно распределение. На ось $y$ — другое. Можно ли найти лучшее направление?

**Показать в ноутбуке:** анимацию проекций при углах $0°$, $45°$, $120°$ и дисперсии каждой проекции.

**Вывод:** Лучшее направление — то, вдоль которого данные имеют **максимальную дисперсию**.

### Поиск оптимального направления

Дисперсия проекций:

$$\text{Var}(\mathbf{u}) = \frac{1}{n-1} \sum_{i=1}^n z_i^2 = \frac{1}{n-1} \mathbf{u}^\top X_c^\top X_c \, \mathbf{u} = \mathbf{u}^\top \mathbf{C} \, \mathbf{u}$$

где $X_c = X - \bar{X}$ — центрированные данные, а $\mathbf{C} = \frac{X_c^\top X_c}{n-1}$ — ковариационная матрица.

Задача оптимизации:

$$\max_{\mathbf{u}} \mathbf{u}^\top \mathbf{C} \, \mathbf{u} \quad \text{при условии} \quad \|\mathbf{u}\| = 1$$

Решается через метод множителей Лагранжа:

$$\mathbf{C} \mathbf{u} = \lambda \mathbf{u}$$

**Это определение собственного вектора!** Максимальная дисперсия достигается на собственном векторе с наибольшим собственным числом.

---

## 3. Ковариационная матрица

### Определение

$$C_{ij} = \frac{1}{n-1} \sum_{k=1}^n (x_{ki} - \bar{x}_i)(x_{kj} - \bar{x}_j) = \text{Cov}(x_i, x_j)$$

Матрица $\mathbf{C} \in \mathbb{R}^{p \times p}$:
- **Симметричная:** $C_{ij} = C_{ji}$
- **Положительно полуопределённая:** $\mathbf{u}^\top \mathbf{C} \mathbf{u} \geq 0$ для любого $\mathbf{u}$
- Диагональные элементы $C_{ii}$ — дисперсии каждого признака
- Внедиагональные $C_{ij}$ — ковариации между признаками

На матричном языке (компактно):

$$\mathbf{C} = \frac{1}{n-1} X_c^\top X_c$$

### Что показывает?

- $C_{ij} > 0$: признаки $i$ и $j$ растут вместе
- $C_{ij} < 0$: обратная зависимость
- $C_{ij} = 0$: линейно независимы

**Показать в ноутбуке:** тепловую карту ковариационной матрицы (рост-вес-возраст-ИМТ).

### Важное замечание

Вычисление через матричное умножение $X_c^\top X_c$ — эффективнее, чем $p^2$ вычислений ковариаций отдельно. Используем NumPy: `np.cov(X.T)` или вручную.

## 4. Eigen Decomposition → PCA

### Спектральная теорема

Поскольку $\mathbf{C}$ симметрична и положительно полуопределена, она **диагонализируема**:

$$\mathbf{C} = \mathbf{V} \Lambda \mathbf{V}^\top$$

где:
- $\Lambda = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_p)$, $\lambda_1 \geq \lambda_2 \geq \ldots \geq \lambda_p \geq 0$ — **собственные числа**
- $\mathbf{V} = [\mathbf{v}_1 | \mathbf{v}_2 | \ldots | \mathbf{v}_p]$ — матрица **собственных векторов** (ортонормированный базис)
- $\mathbf{V}^\top \mathbf{V} = \mathbf{V} \mathbf{V}^\top = \mathbf{I}$ (унитарная матрица)

### Геометрический смысл

Собственные векторы $\mathbf{v}_i$ — **главные оси** эллипсоида рассеяния данных.  
Собственные числа $\lambda_i$ — **длины этих осей** (дисперсия вдоль каждой оси).

**Нарисовать на доске:** эллипс с двумя осями, показать $\mathbf{v}_1$, $\mathbf{v}_2$, $\lambda_1 > \lambda_2$.

### Алгоритм PCA

1. **Центрировать** данные: $X_c = X - \bar{X}$
2. **Ковариационная матрица:** $\mathbf{C} = \frac{1}{n-1} X_c^\top X_c$
3. **Eigen decomposition:** $\mathbf{C} \mathbf{v}_i = \lambda_i \mathbf{v}_i$ для $i = 1, \ldots, p$
4. **Сортировать** по убыванию $\lambda_i$
5. **Матрица проекции:** $W = [\mathbf{v}_1 | \ldots | \mathbf{v}_k] \in \mathbb{R}^{p \times k}$
6. **Проецировать:** $Z = X_c W \in \mathbb{R}^{n \times k}$

### Explained Variance Ratio

Доля дисперсии, объяснённой $i$-й компонентой:

$$r_i = \frac{\lambda_i}{\sum_{j=1}^p \lambda_j}$$

Правило большого пальца: выбрать $k$ такое, что $\sum_{i=1}^k r_i \geq 0.90$ (90% дисперсии).

**Показать в ноутбуке:** PCA из нуля через `np.linalg.eigh`, визуализация собственных векторов.

### Ключевое свойство: декорреляция

В пространстве главных компонент признаки **не коррелированы**:

$$Z^\top Z / (n-1) = \text{diag}(\lambda_1, \ldots, \lambda_k) = \Lambda_k$$

Это прямо следует из ортогональности $W$.

## 5. SVD: тот же результат, но лучше

### Определение SVD

Любая матрица $X_c \in \mathbb{R}^{n \times p}$ разлагается как:

$$X_c = U \Sigma V^\top$$

- $U \in \mathbb{R}^{n \times n}$ — **левые** сингулярные векторы (ортогональная матрица)
- $\Sigma \in \mathbb{R}^{n \times p}$ — **диагональная**: $\sigma_1 \geq \sigma_2 \geq \ldots \geq 0$ (сингулярные числа)
- $V \in \mathbb{R}^{p \times p}$ — **правые** сингулярные векторы (ортогональная матрица)

### Связь с Eigen decomposition

$$X_c^\top X_c = (U \Sigma V^\top)^\top (U \Sigma V^\top) = V \Sigma^\top U^\top U \Sigma V^\top = V \Sigma^2 V^\top$$

Сравниваем с $\mathbf{C} = V \Lambda V^\top$:

$$\lambda_i = \frac{\sigma_i^2}{n-1}$$

**Вывод:** Правые сингулярные векторы $V$ = собственные векторы $\mathbf{C}$.

### Проекция через SVD

$$Z = X_c V_k = U \Sigma V^\top V_k = U_k \Sigma_k$$

Проекцию можно вычислить без явного подсчёта ковариационной матрицы!

### Почему SVD лучше?

| Метод | Проблема |
|---|---|
| `eigh(C)` | Нужно вычислить $X_c^\top X_c$ → квадрирование сингулярных чисел → потеря точности |
| `svd(X_c)` | Работает с исходной матрицей → численно стабильнее |

Пример: если $\sigma_{\min} \approx 10^{-8}$, то $\lambda_{\min} = \sigma_{\min}^2 \approx 10^{-16}$ — уже у границы машинной точности.

Именно поэтому `sklearn.decomposition.PCA` использует SVD внутри (`scipy.linalg.svd`).

**Показать в ноутбуке:** equivalence через `np.linalg.svd`.

## 6. Low-rank Approximation

### Теорема Эккарта-Янга (Eckart-Young, 1936)

Для матрицы $A$ ранга $r$ наилучшее приближение ранга $k$ по норме Фробениуса:

$$A_k = \arg\min_{\text{rank}(B) = k} \|A - B\|_F = U_k \Sigma_k V_k^\top$$

Ошибка приближения:

$$\|A - A_k\|_F^2 = \sum_{i=k+1}^r \sigma_i^2$$

**Это доказывает оптимальность PCA** — среди всех линейных снижений размерности до $k$ PCA минимизирует среднеквадратичную ошибку реконструкции.

### Сжатие изображений

Размер оригинала: $n \times p$ чисел  
Размер $k$-ранговой аппроксимации: $k(n + p + 1)$ чисел  
Коэффициент сжатия: $\dfrac{np}{k(n+p+1)}$

**Показать в ноутбуке:** сжатие изображения при разных $k$, график качество vs. сжатие.

### Применения low-rank approximation

- **Рекомендательные системы** (Netflix Prize): матрица рейтингов фильмов
- **Шумоподавление:** сигнал + шум → SVD → первые $k$ компонент (сигнал), остальные (шум)
- **Латентный семантический анализ (LSA):** документ-термин матрица
- **Сжатие весов нейросетей** (LoRA: Low-Rank Adaptation)

## 7. Практика: PCA на реальных данных

### Чек-лист перед запуском PCA

1. ✅ Удалить пропуски
2. ✅ **Стандартизировать данные** (`StandardScaler`) — иначе признаки с большой шкалой доминируют
3. ✅ Выбрать число компонент через `explained_variance_ratio_`
4. ✅ Визуализировать в 2D, проверить разделимость классов

### Датасет: MNIST Digits

**Показать в ноутбуке:**
- Для 90% дисперсии достаточно ~21 компоненты из 64
- 2D-проекция PCA показывает кластеры цифр
- «Eigendigits» — первые главные компоненты как изображения
- Реконструкция при разных $k$

### Когда 2D-визуализация обманывает?

2D PCA показывает только $r_1 + r_2$ дисперсии (часто 15–30%). Если классы перекрываются — не значит, что они неразделимы! В исходном или в PCA с $k=20$ пространстве разделение может быть хорошим.

## 8. Ограничения PCA

### 1. Только линейные зависимости

PCA ищет линейные проекции. Нелинейные структуры (спираль, тор, многообразие) теряются.

**Показать в ноутбуке:** два концентрических кольца → PCA не разделяет классы.

### 2. Чувствительность к масштабу

Признак в сантиметрах vs признак в метрах — PCA найдёт «главную компоненту» вдоль сантиметрового признака просто потому что у него больше числовой разброс.

**Правило:** всегда применять `StandardScaler` перед PCA.

### 3. Интерпретируемость

Каждая главная компонента — линейная комбинация **всех** исходных признаков. Сложно объяснить бизнесу «что такое $PC_1$».

Альтернатива: **Sparse PCA** — принудительно делает компоненты разреженными.

### 4. Нет учёта меток классов

PCA — **unsupervised**. Максимальная дисперсия ≠ максимальная разделимость классов.

Альтернатива: **LDA (Linear Discriminant Analysis)** — максимизирует разделимость.

### Альтернативы PCA

| Метод | Когда использовать |
|---|---|
| **Kernel PCA** | Нелинейные структуры, малые датасеты |
| **t-SNE** | Визуализация, сохранение локальной структуры |
| **UMAP** | Быстрее t-SNE, сохраняет глобальную структуру |
| **ICA** | Нужна статистическая независимость (не просто некоррелированность) |
| **NMF** | Неотрицательные данные (тексты, изображения), интерпретируемые части |
| **Autoencoder** | Нелинейное сжатие, много данных, есть GPU |

## Резюме

**PCA в трёх строках:**

```python
X_c = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(X_c, full_matrices=False)
Z = U[:, :k] * S[:k]   # compressed representation
```

**Когда применять PCA:**
- До обучения модели для ускорения и борьбы с мультиколлинеарностью
- Для визуализации многомерных данных в 2D/3D
- Для шумоподавления и сжатия

**Когда не применять:**
- Нелинейные зависимости → t-SNE / UMAP / Kernel PCA
- Важна интерпретируемость признаков → feature selection
- Небольшое число признаков с известным смыслом
