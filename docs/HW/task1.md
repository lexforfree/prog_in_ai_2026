## Подсказки

### Псевдообратная матрица в NumPy:
```python
theta = np.linalg.inv(X.T @ X) @ X.T @ y
# или с регуляризацией:
theta = np.linalg.inv(X.T @ X + lambda_reg * np.eye(X.shape[1])) @ X.T @ y
```

### Обработка ошибок:
Если матрица необратима (singular matrix), используйте `np.linalg.pinv()` или увеличьте λ.
